# 🎌 AnimeVerse

AnimeVerse is a modern anime discovery platform inspired by streaming services like Crunchyroll and Netflix. Built with React and Tailwind CSS, it provides an immersive experience for anime fans to explore trending, popular, and top-rated anime through a sleek and responsive user interface.

---

## ✨ Features

### 🏠 Home Experience
- Dynamic Hero Banner
- Auto-Sliding Featured Anime Showcase
- Trending Anime Collection
- Popular Anime Collection
- Top Rated Anime Collection

### 🔍 Smart Search
- Real-Time Anime Search
- Instant Search Suggestions
- Direct Navigation to Anime Details Pages

### 📖 Anime Details
- Detailed Anime Information
- Synopsis & Description
- Ratings & Reviews Section
- Episode Count
- Studio Information
- Genre Information
- Trailer Access

### 🎭 Explore Categories
- Trending Anime
- Popular Anime
- Top Rated Anime
- Anime Movies
- Anime Genres

### 🎨 Modern User Interface
- Dark Theme Design
- Responsive Layout
- Smooth Animations & Transitions
- Interactive Anime Cards
- Streaming Platform Inspired Experience

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/animeverse.git
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
